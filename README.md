An offline guide + tracker for all 55 GTA VI PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze). Every trophy has a guide written in the maker's own words, citing its sources, plus a tracker that saves your progress, a spoiler-safe mode, and a 4-stage roadmap to the platinum. Works fully offline.

## Run it

```sh
node serve.ts --port 8901
```
