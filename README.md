Leonida Trophy Guide — an offline guide and tracker for all 55 official GTA VI PlayStation 5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden). Every trophy has its official name and description as PlayStation publishes it, plus a guide in our own words with its source named, a missable flag where it applies, and a roadmap to the platinum in four stages. The tracker is a checklist saved in the browser (localStorage) with export and import as JSON, a share link, filters by kind, grade and earned state, and a spoiler-safe mode that blurs un-earned story trophies. Static files only — it works with the network off.

## Run it

```sh
node serve.ts --port 8901
```
